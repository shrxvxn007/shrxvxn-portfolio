# tests/golden/

This directory holds reference outputs that the regression gates diff
against. There are two kinds of files registered here, with deliberately
different roles -- keep them straight when reviewing a PR:

1. **Golden files** -- committed-by-hand reference outputs. The strategy
   regression gate (`scripts/check_replay_golden.py`) diffs `aster_replay`
   stdout against `analytics_ci.json`. Edit the golden ONLY when an
   intentional change to the strategy algorithm changes the analytics
   numbers; otherwise drift here is a real bug.

2. **Snapshot mirrors** (NOT in this directory) -- generated by
   `scripts/capture_ci.sh` and committed under `ci/` (one level up).
   These mirror the live state of github.com CI at capture time.
   They are NOT edited by hand; they drift; the test in
   `tests/test_ci_snapshot.py` flags drift before it reaches a tag.

If a contributor is tempted to "fix" offline drift by hand-editing
files under `ci/`, send them back to `./scripts/capture_ci.sh` instead.
Manual edits get overwritten on the next 6-hour cron refresh.

If the test in `tests/test_ci_snapshot.py` fires locally and you have
NOT intentionally changed the strategy algorithm, the safest move is:
  1. `./scripts/capture_ci.sh --runs 3` (refresh the offline mirror)
  2. re-run the test (`python3 tests/test_ci_snapshot.py`)
  3. if the second run still fails, investigate the github-side CI;
     a real failure means `ci/` should NOT say `CI - passing`.
